# 个人资料库

基于 AI 漫剧创作者工作流程的本地素材归档与管理工具。把图片、视频、音频、拉片资料、热梗和创作笔记放进一套可检索的资料体系，按项目找到需要的内容。

## 可以用来做什么

- **整理素材**：接入本地素材文件夹，浏览图片、视频和音频，用分类、标签、搜索与收藏整理内容。
- **积累拉片资料**：按作品组织原片、分集报告和镜头参考，方便创作时回看。
- **建立热梗库**：整理台词、画面提示、声音提示和适用场景，保留来源与使用说明。
- **保存笔记与小说**：管理知识笔记、作品章节和历史存稿，查找本机恢复草稿。
- **围绕项目使用资料**：将素材与知识关联到项目，减少在多个文件夹之间反复寻找。

本工具负责归档、检索和管理，不会自动替你生成漫剧、续写小说或完成拉片分析。

## 开始使用

**[下载 Windows 工具包](https://github.com/yuanyi0612-ops/personal-library/releases/latest)** · [查看使用说明](使用说明.md)

在发布页的 Assets 中选择 `personal-library-windows-x64-2026.10.21.zip`。GitHub 自动提供的 “Source code” 压缩包仅包含本仓库的介绍与文档。

1. 将下载的压缩包完整解压到自己有写入权限的文件夹。
2. 双击根目录的 `PersonalLibrary.exe`。
3. 在页面中接入自己的素材文件夹，或建立笔记与卡片。

无需安装 Python。请保留整个 `00-程序框架` 文件夹，不要只复制一个可执行文件。

程序优先打开桌面窗口；电脑缺少所需的网页运行环境时，会尝试使用系统默认浏览器。也可双击 `启动网页版.cmd`。

## 资料保存在本机

首次启动会在程序旁创建七个分类目录：素材库、知识库、笔记小说库、拉片库、剪辑知识库、热梗库和项目。发布包不附带任何人的素材、笔记、小说、数据库或浏览器资料。

接入现有文件夹时，原文件保留在原位置。项目引用同一份素材时，不必为了分类再复制一份。

`_系统数据` 中包含数据库和运行资料，不是可随意删除的缓存。完整备份方法见 [使用说明](使用说明.md)。

## 音频与运行环境

适用于 Windows 10/11 的六十四位电脑。浏览器原生支持的音频可直接试听；需要兼容转码的格式需自行配置音频转换工具，详见 [使用说明](使用说明.md)。
